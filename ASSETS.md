# Assets

Every asset that ships with Tibu, where it came from, and its license.
If you add a file to a pack (`packs/<id>/icons/` or `packs/<id>/audio/`) or a theme
folder, add a row here with its source and license. Only original work (MIT) or
CC0 files are accepted.

## Art

All shipped block art, tray icons, pack icons and theme pictures are **generated in
code** at load time on 128 x 128 canvases. There are no image files in the shipped
packs.

| What | Source | License |
| --- | --- | --- |
| Block faces (solid colors, shape marks, letters, numbers and dots, music notes) | Generated by `src/content/art/` (marks, basic patterns) | MIT (Tibu code) |
| Nature textures (grass, dirt, sand, water, wood, leaves, flowers, stone, snow, ice, hay, moon rock) | Generated by `src/content/art/patterns-nature.ts` | MIT (Tibu code) |
| Building textures (bricks, planks, windows, doors, roofs, glass, lamp, star light) | Generated by `src/content/art/patterns-building.ts` | MIT (Tibu code) |
| Animal faces | Generated by `src/content/art/animal-face.ts` | MIT (Tibu code) |
| Tray, pack and theme picker icons | Generated by `src/content/art/icons.ts` | MIT (Tibu code) |
| Letter and number glyphs | Drawn with the device's own system fonts; no font files ship | n/a |

The art is original and deliberately soft and rounded. It does not copy or imitate
any other game's textures.

## Sound

Block tap sounds are named synth presets (`moo`, `baa`, `oink`, `neigh`, `cluck`,
`quack`, `meow`, `woof`, `tweet`, `ribbit`, `squeak`, `note`, `chime`, `pop`,
`splash`, `rustle`, `knock`, `ding`) **synthesized with the Web Audio API** in
`src/audio/`. The list is the `synthPreset` enum in `schemas/pack.schema.json`.

| What | Source | License |
| --- | --- | --- |
| Block tap sounds (synth presets) | Synthesized at runtime by `src/audio/` | MIT (Tibu code) |
| Audio files in `packs/*/audio/` | None shipped | n/a |

UI sound effects (place, smash, undo, mode switch, celebrate, tap, whoosh, sleep
lullaby) and the optional generative background music are also synthesized at
runtime (`src/audio/sfx.ts`, `src/audio/music.ts`). No sample files ship.

| What | Source | License |
| --- | --- | --- |
| UI sound effects | Synthesized at runtime by `src/audio/sfx.ts` | MIT (Tibu code) |
| Background music (off by default) | Generated at runtime by `src/audio/music.ts` | MIT (Tibu code) |

## Voice

All spoken lines are AI-generated at build time (no human recordings) and committed under `voice/<lang>/`.

| Item | Details |
| --- | --- |
| Model | [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) by hexgrad, revision `f3ff3571791e39611d31c381e3a41a3af07b4987` (v1.0 weights `kokoro-v1_0.pth`) |
| Model license | Apache-2.0 (weights and voicepacks; per the model card, training audio was permissively licensed/public domain or synthetic) |
| Voice | `af_heart` (American English, warm female voice), speed 0.9 |
| Software | `kokoro` 0.9.4 (Apache-2.0), `misaki[en]` 0.9.4 G2P (Apache-2.0), spaCy `en_core_web_sm` 3.8.0 (MIT), espeak-ng via `espeakng-loader` (GPL-3.0, build-time tool only; not shipped) |
| Lines | `voice/LINES.json` (text, MIT with the code) |
| Clips | `voice/en/<lineId>.m4a`: AAC-LC in MP4, mono, 24 kHz, 32 kbps target, silence-trimmed and peak-normalized; encoded with `afconvert` (macOS) or `ffmpeg` |
| Manifest | `voice/<lang>/manifest.json` records the text/voice/model/encoding hash of each clip so `npm run voice` only regenerates changed lines |
| Regenerate | `npm run voice` (`--force`, `--lang <code>`, `--sync-only`). Needs `uv`; the Python env lives in `scripts/voice/.venv` (gitignored), model cache in `scripts/voice/.cache` (gitignored) |

If a clip is missing at runtime, the app falls back to the browser's built-in speech synthesis. Nothing is fetched from the network at runtime.
